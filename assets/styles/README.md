# Style reference images

Each catalog haircut has a folder here named by its `id` (see `constants/haircuts.ts`):

```
assets/styles/<id>/
  thumb.png     # catalog card image (3:4)
  ref_1.png     # reference gallery image 1
  ref_2.png
  ref_3.png
  ref_4.png
```

## Current state
These are **branded placeholders** generated by
`scripts/generate-style-placeholders.js` (regenerate with `node scripts/generate-style-placeholders.js`).
They exist so the app is fully populated and screenshot-ready.

## Swapping in real photos
Drop real licensed/approved reference photos into the same file paths (keep the
same filenames and the 3:4 aspect ratio). **No code change is required** — the
catalog references these paths statically.

Guidelines for real photos:
- Portrait orientation, ~600×800 or larger, clear view of the haircut.
- Prefer neutral/consistent backgrounds so the gallery looks cohesive.
- Ensure you have the rights to ship each image in the app.
